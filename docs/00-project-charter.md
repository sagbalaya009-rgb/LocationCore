# Project charter

Build an offline-capable, controlled REAL / STATIC / MOVEMENT / ROUTE location system for the exact connected TECNO KL5 build. The final system must fail back to REAL, have an independent ADB disable path, and be uninstallable. It must not target banking, identity, game, or other anti-abuse detection systems.

The project is complete only after real-device acceptance tests and repository push. A compiled app or a mock location demonstration alone does not satisfy the charter.

Current gate: read-only investigation is underway. No stock recovery package matching `260615V2258` has been validated; bootloader is locked; no privileged modifications are authorized by the available recovery evidence.
